# Carp Studio 资源导航站
鲤鱼工作室综合资源导航页面

## 📖 简介
这是一个面向电脑爱好者、Minecraft玩家、硬件发烧友、装机运维人员的一站式资源导航网页。
聚合各类纯净软件、系统维护工具、硬件查询网站、我的世界模组平台、网盘工具、在线实用工具、学习资料站点。

本导航站设计为深色简约风格，无多余广告，所有链接新开页面访问，方便日常快速检索各类资源。

## ⚠️ 使用重要提醒
1. 在国内站点下载软件时，**只选择普通下载，禁止点击高速下载、一键下载**，防止捆绑垃圾软件。
2. 破解类软件、非正版资源存在病毒、侵权风险，仅限个人学习研究，禁止商用传播。
3. 文件下载完成建议使用杀毒软件扫描；开源素材请仔细阅读版权协议。
4. 部分外部网站弹窗广告较多，弹窗直接关闭，不要安装网页弹出的任何程序。
